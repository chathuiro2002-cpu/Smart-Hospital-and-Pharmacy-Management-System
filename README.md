# Smart Hospital & Pharmacy Management System

## Project Overview

The Smart Hospital & Pharmacy Management System is a management application developed to support hospital reception, doctor checking, and pharmacy management processes.

The system helps organize patient information, appointments, prescriptions, pharmacy queues, and medicine inventory.

## Main Features

- Patient Registration
- Appointment Management
- Doctor Management
- Prescription Management
- Pharmacy Queue Management
- Medicine Inventory Management
- Low-Stock Monitoring

## Technologies Used

- Java
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP

## Installation and Setup

1. Install XAMPP on your computer.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin and create the required database.
5. Import the project's SQL database file, if available.
6. Configure the database connection settings in the project.
7. Open the project in your browser using `http://localhost/your-project-folder/`.

## Database

This project uses MySQL for database management. Import the project's SQL file to create the required tables, if provided.
